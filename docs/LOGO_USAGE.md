# CareHome Logo Assets

Professional logo variations for the CareHome Management System project.

## Logo Files

### 1. **carehome-logo.svg** (Default Full Logo)
- **Best for**: Websites, welcome pages, documentation
- **Dimensions**: 300x300px (scalable SVG)
- **Design**: Centered icon with "CareHome Management System" text below
- **Use case**: Headers, landing pages, formal documents

Example usage in HTML:
```html
<img src="{% static 'images/carehome-logo.svg' %}" alt="CareHome Management System" width="300">
```

---

- **Use case**: Sidebars, buttons, small spaces, favicon

## Design Elements

### Colors Used
- **Primary Teal**: `#2d7a7a` - Main background circle
- **Accent Green**: `#20c997` - Secondary highlights
- **White**: `#ffffff` - Heart symbol (care)
- **Gold/Orange**: `#f0ad4e` - Health chart indicator

### Symbol Meaning
- **Heart**: Represents care and compassion
- **Health Chart**: Shows progress tracking and health monitoring
- **Teal Circle**: Professional, trustworthy, healthcare-related

## Technical Specifications

All logos are in **SVG format** (Scalable Vector Graphics):
- ✅ Resolution-independent (perfect at any size)
- ✅ Small file size (ideal for web)
- ✅ Support for filters and effects
- ✅ Easy to customize (change colors in SVG code if needed)
- ✅ Accessible (includes role and aria-label attributes)

---

## Color Customization

To change colors in any SVG file, edit these color codes:

```svg
<!-- To change the circle background -->
fill="#2d7a7a" → fill="#YOUR_COLOR"

<!-- To change the heart -->
fill="#ffffff" → fill="#YOUR_COLOR"

<!-- To change the chart line -->
stroke="#f0ad4e" → stroke="#YOUR_COLOR"

<!-- To change text color -->
fill="#2d7a7a" → fill="#YOUR_COLOR"
```

## Alternative Formats

To convert these SVG logos to other formats:

### PNG (Raster)
- Right-click SVG → Convert to PNG using online tool
- Use [CloudConvert](https://cloudconvert.com/) or similar
- Recommended resolutions: 512x512px, 1024x1024px

### PDF (Print)
- Open SVG in Illustrator/Inkscape
- Export as PDF for high-quality printing

### WebP (Modern Web)
- Convert using online tools for better web performance
